# Generate test cases ourselves instead of converting FloorSet samples

Lab3 is derived from ICCAD 2026 Problem C, which ships the FloorSet-Lite dataset (CC BY 4.0), so converting FloorSet samples looked like the obvious source of test cases. We generate all five cases with our own FloorSet-style generator instead: it cuts a known packing of the outline, so every case is feasible by construction with the stricter rules of this lab (fixed outline, aspect ratio bound, preplaced blocks), and whitespace and constraint density can be tuned per case. FloorSet's training and validation layouts are public on Hugging Face, so converted cases could be matched against them by area targets and preplaced positions. FloorSet layouts also have almost no whitespace and often violate MIB/boundary, so they would need reworking anyway. FloorSet stays in use as a public benchmark for tuning the reference solver, and the spec cites it.
